2.1.20 Media Queries 
 Media queries are a CSS feature that allow styles to be applied conditionally based on characteristics of the device or 
 viewport, such as screen width, height, orientation, or resolution. They are essential for creating responsive web designs 
 that adapt seamlessly to different devices, like desktops, tablets, and smartphones. 
 The example below demonstrates applying simple background and foreground colors based on various screen sizes. The 
 default style, outside of any @media at rule , deﬁnes the default background and foreground colors as white text on a 
 green background. Subsequent at rules redeﬁne the style that only take effect at various screen size rages, e.g., black on 
 white for screen widths between 750 and 1000 pixels. 
 app/labs/lab2/MediaQueriesDemo.css 
 /* Default styles */ 
 .wd-media-queries-demo { 
 background-color : green ; 
 color : white ; 
 } 
 /* Style between 750px and 1000px */ 
 @media ( min-width : 750px ) and ( max-width : 1000px ) { 
 .wd-media-queries-demo { 
 background-color : yellow ; 
 color : black ; 
 } 
 } 
 /* Style between 1000px and 1250px */ 
 @media ( min-width : 1000px ) and ( max-width : 1250px ) { 
 .wd-media-queries-demo { 
 background-color : blue ; 
 color : white ; 
 } 
 } 
 /* Style for widths greater than 1250px */ 
 @media ( min-width : 1250px ) { 
 .wd-media-queries-demo { 
 background-color : red ; 
 color : white ; 
 } 
 }

 The component below applies the wd-media-queries-demo class rendering the content in various combinations of 
 background and foreground colors as the browser window is resized. 
 app/labs/lab2/MediaQueriesDemo.tsx 
 import "./MediaQueriesDemo.css" ; 
 export default function MediaQueriesDemo() { 
 return ( 
 <div className = "wd-media-queries-demo" > 
 <h1> Media Query Demo </h1> 
 <p> 
 This demo uses CSS media queries to change colors based on screen width: 
 </p> 
 <ul> 
 <li> Default is White text on Green background </li> 
 <li> 750px to 1000px: Black text on Yellow background </li> 
 <li> 1000px to 1250px: White text on Blue background </li> 
 <li> Above 1250px: White text on Red background </li> 
 </ul> 
 </div> 
 ); 
 }
