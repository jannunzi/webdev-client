2.1.11 Styling an HTML Tag's Corners with CSS 
 Tag border corners can be styled to be rounded to soften their look and feel. All corners can be styled together or 
 individual corners can be styled separately. How rounded a corner is can be conﬁgured by setting the corner's border 
 radius. To practice rounding some corners, copy the CSS and HTML below into index.css and Corners.tsx . Import and 
 conﬁrm the browser renders as shown.
