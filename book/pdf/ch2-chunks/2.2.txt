2.2 Decorating Documents with React Icons 
 React icons is a CSS library that aggregates icons from various sources including Fontawesome , Bootstrap , and 
 Heroicons . Install React icons from the root of your project as shown below. 
 npm install react-icons 
 Head over to https://react-icons.github.io/react-icons to search for icons of interest. Search for icons by typing a topic in 
 the search box. Here are a few example searches found from several icon sources.
