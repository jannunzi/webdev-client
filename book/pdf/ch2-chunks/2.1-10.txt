2.1.7 Styling an HTML Tag's Foreground Color with CSS 
 Foreground colors can be conﬁgured using the CSS color property as follows 
 . some-css-selector { 
 color : blue ; 
 } 
 /* selects some DOM element */ 
 /* sets color property to blue */ 
 Colors can be deﬁned in various ways: 
 ● As strings, e.g., white , red , blue , etc. There are thousands of declared color names. [REF] 
 ● As hexadecimals, e.g., #ABCDEF, where each group of 2 digits, from left to right specify the amound of red, green 
 and blue. 
 ● As RGB, e.g., rgb(12, 34, 56), where each digit, from left to right, speciﬁes the amound of red, green and blue. 
 Here are a couple of examples: 
 . the-sun { color : rgb ( 255 , 255 , 0 ); } . the-sky { color : blue ; } . ketchup { color : #FF0000 ; }
