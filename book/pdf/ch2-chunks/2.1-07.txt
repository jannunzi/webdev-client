2.1.5 Selecting HTML Content Based on the Document Structure 
 Selectors can be combined to refer to tags in particular places in the document. A set of selectors separated by a space 
 can refer to elements in a hierarchy. For instance: .selector1 .selector2 { … } refers to an element whose class is .selector2 
 and is inside some ancestor whose class is .selector1 . Alternatively, separating class selectors with the ">" character 
 establishes a direct parent/child relationship. To practice selecting elements using a set of selectors, copy the following 
 content in page.tsx . The code below does not show ellipses as previous examples, but the code is intended to be copied 
 at the end of the ﬁle shown. Be sure to include the code within the function's return and within the wrapping <div> .
